CSS Units — Complete Demonstration

1. Absolute Units — Small to Large

Absolute units represent fixed CSS measurements.

1Q — Quarter Millimeter
1mm — Millimeter
1px — Pixel
1pt — Point
1pc — Pica
1cm — Centimeter
1in — Inch

2. Font Relative Units

1rem

1rem = root element font-size.

1em

1em = current element's font-size context.

3. Percentage Unit — %

50%

4. Viewport Units

10vw — Viewport Width
10vh — Viewport Height
10vmin — Smaller Viewport Dimension
10vmax — Larger Viewport Dimension

5. Small, Large & Dynamic Viewport Units

10svw — Small Viewport Width
10svh — Small Viewport Height
10lvw — Large Viewport Width
10lvh — Large Viewport Height
10dvw — Dynamic Viewport Width
10dvh — Dynamic Viewport Height

6. Container Query Units

These units are calculated relative to the size of a container rather than the browser viewport.

20cqw
20cqh
20cqi
20cqb
20cqmin
20cqmax

7. Grid Fraction Unit — fr

The fr unit represents a fraction of the available space inside a CSS Grid container.

1fr
2fr
3fr
